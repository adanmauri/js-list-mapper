> [!NOTE]
> **Archived project (2017).** Kept public for historical and reference purposes only; it is no longer maintained.
>
> JS List Mapper extracts the items of paginated web listings (e.g. search results) into JavaScript objects, using XPath selectors for the items, the pagination and the search box. It was developed as part of research at the Facultad de Informática, Universidad Nacional de La Plata (UNLP).
>
> The example plugins (MercadoLibre, YouTube, IMDb, AutoCosmos) target the page markup of 2017, so they most likely no longer work.
